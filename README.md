# Duck or no duck ?!

A bright top-down survival game: eat, grow and evolve through a food web of fruit, meat and fish.
Built in Godot 4 and playable in the browser.

**Play:** https://barmoshe.github.io/duck-or-no-duck/

- `game/` is the Godot project (scenes, scripts, tests).
- `public/` is the committed web export that GitHub Pages serves.
- `tools/` holds the build, test and screenshot scripts (`tools/build_web.sh` rebuilds `public/`).
- `STATUS.md` has where the game is and what is next.
