# Duck or no duck ?! — brief

Immutable once written. Track changes as decisions, not edits.

- One-liner: a landscape mobile homage to *Everything is Crab* where evolution can go duck (or not): hatch as a slime, eat, evolve, survive the bosses.
- For / job-to-be-done: Bar's own game experiment in lab/: the best possible "Everything is Crab" on a phone, as a full working MVP, deployed to Vercel, built in Godot.
- v1 "done": a full 15-minute run is playable on a phone in the browser: open world, ecosystem, level-up evolutions visible on the body, bosses, final boss, meta unlocks.
- Constraints: Godot 4.7.2, web export (single-threaded, iPhone Safari), landscape only, no sibling repo for now, deployed on Vercel.
- Visual style: hand-authored pixel art (Everything is Crab is pixel art); the hero starts as a slime and its art evolves with every mutation.
- After-demo intent: playtest on the phone, then decide on store builds.
- Open questions: none at brief time.
