# Duck or no duck ?! — local conventions

- Godot 4.7.2 project in game/, everything built in code (main.tscn is a script).
- Pixel art at an integer scale (Game.fit_pixels, short side ~225 px). Nearest filtering, no fractional scaling, no free rotation of sprites.
- Puddle (the player, look["darwin"]) = hand-drawn flat pixel art in Everything-is-Crab's Darwin style: game/scripts/art/darwin/body.gd (DarwinArt: gumdrop body, anchors, back/front part layers, poses) + darwin/parts.gd (49 parts, generated by tools/art/darwin_parts.py — edit the .py, regenerate). Review with tests/darwin_board.gd.
- Animals and bosses = hand-drawn side-view sprites in the same style: game/scripts/art/darwin/animals.gd (DarwinAnimals: rows, legs walk frames, alt body, eyes, mouth, recolor, zoom), generated by tools/art/darwin_animals.py — edit the .py, regenerate. DarwinArt.species_frames animates them. Anatomy is the facade (frames/single/key_of/render). Colors only from DarwinArt.KEY / Pal.
- Food = hand-drawn in the same style: game/scripts/art/darwin/food.gd (DarwinFood: <type>_<rarity> -> 4 eaten stages), generated by tools/art/darwin_food.py (edit the .py, regenerate; --board out.png to review). Props draws food_<type>_<rarity>_<stage>.
- Crab reference (wiki icons + evolution catalog + mechanics): research/crab-ref/. Reference only, never shipped.
- sim/ and data/ never touch nodes; World emits signals, main.gd opens screens.
- Tools: tools/check.sh (parse), tools/test.sh (logic + bot runs), tools/shot.sh (Xvfb screenshots), tools/build_web.sh, tools/webtest.sh, tools/publish.sh (stages public/ for GitHub Pages).
- Sound = game/scripts/autoload/sfx_synth.gd (SfxSynth: every recipe + LEVEL/PRIORITY/VARIANTS mix tables); Sfx plays it. Review with tests/sfx_board.gd (renders WAVs + a punch/level table) before shipping a sound change.
- Review art with tests/puddle_board.gd, tests/darwin_board.gd (parts) and tests/animal_board.gd (animals | bosses) before shipping it.
